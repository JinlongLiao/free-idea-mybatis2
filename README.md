# MyBatis Workbench

![MyBatis Workbench](src/main/resources/META-INF/pluginIcon.svg)

MyBatis Workbench 是一款面向数据库管理和 MyBatis 开发的 IntelliJ 插件。支持 Mapper 接口与 XML 双向导航，也可从 IDEA 原生数据库工具或内置数据库工作台选表生成代码。

## 功能

- 在 Mapper 接口的方法与 XML 中对应的 SQL 语句之间双向跳转。
- 提供 Mapper XML 模板、参数补全、检查和快速修复。
- 通过 MyBatis Generator 界面按数据库表生成模型、Mapper 接口和 XML，支持按配置生成 Swagger 模型注解。
- 识别 Spring XML 和 `@MapperScan` 中注册的 Mapper。

## 构建与安装

0.1.1 的安装、连接迁移和兼容范围见 [升级指南](<0.1.1 升级指南.md>)。对外发布内容见 [发布文案](<0.1.1 发布文案.md>)。

使用 JDK 25，将 `JAVA_HOME` 指向对应 JDK 后，在仓库根目录执行：

```bash
./gradlew test buildPlugin verifyPluginStructure
```

Windows PowerShell 使用 `./gradlew.bat test buildPlugin verifyPluginStructure`。首次构建需要下载 Gradle、IDEA SDK 和 Maven 依赖。构建完成后，在 IDEA 的 **Settings / Preferences → Plugins → 齿轮菜单 → Install Plugin from Disk…** 选择 `build/distributions/mybatis-workbench-0.1.1.zip`，并按 IDE 提示重启。

开发时可用 `./gradlew runIde` 启动隔离的开发实例。插件结构检查验证打包产物，实际功能请在 IDE 中用 MyBatis 项目验证。

## 使用

1. 打开同时包含 Mapper 接口和对应 XML 的项目。确认 XML 的 `namespace` 对应接口全限定名，SQL 语句的 `id` 对应接口方法名。
