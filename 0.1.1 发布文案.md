# MyBatis Workbench 0.1.1 发布文案

## 发布标题

MyBatis Workbench 0.1.1 带来内置数据库工作台

## 发布正文

Free Enhanced MyBatis2 更名为 **MyBatis Workbench**。这一版加入数据库工作台，可连接数据库、浏览对象和执行查询。在启用 Java 插件的宿主中，也可以从关系库表节点生成 MyBatis 实体、Mapper 接口和 XML。

- 支持 MySQL、PostgreSQL、MariaDB、SQLite、SQL Server、Oracle、H2，以及 Redis、MongoDB、Elasticsearch。
- JDBC 驱动默认从 Maven Central 下载，也可配置自定义仓库。SQLite 和 H2 可直接选择已有数据库文件。
- 可在独立标签页用 AND 组合数据库端筛选条件，并排序、翻页和增删改表数据。双击可编辑单元格即可修改，新增行可逐列填写数据库默认值、输入值或 SQL NULL。可以导入或导出 CSV，并查看只读 DDL。控制台支持取消正在运行的普通 SQL。比较表结构后，可预览或保存生成的 SQL 草案。
- 生成的 Mapper 按数据库方言引用含空格的库名、Schema 名和表名。手工赋值的复合主键会完整保留在 INSERT 中。
- 可从同一数据源选择多张表批量生成，并在写文件前检查 Java 输出名称冲突。
- SQL 控制台可执行光标所在的单条语句，或执行显式选中的 SQL。估算计划仅接受一条语句。
- 从 MySQL 或 MariaDB 的库节点、PostgreSQL 或 H2 的 Schema 节点打开 SQL 控制台时，查询、估算计划和补全使用所选范围。
- Redis 单机与 Cluster 支持对象树键过滤和游标翻页，每页最多展示 100 个键。从树打开控制台会继承当前浏览范围。列表成员续页只发送一次请求，每页最多读取 20 项。整键删除会核对原内容，复合键快照超限或 Stream 有消费组时会拒绝删除。
- MongoDB 支持按字段或用 Extended JSON 新增文档，双击字段即可编辑，校验失败保留输入。
- Elasticsearch 支持用户名和密码或 API Key、按连接设置 HTTPS 证书校验，以及取消等待 Query DSL 搜索结果。双击结果行可打开文档编辑。
- 刷新 Redis 主节点、MongoDB 数据库或集合、Elasticsearch 索引或别名时保留原选择。原目标消失时需重新选择。
- 宿主启用原生专业数据库功能时沿用原生窗口，其他宿主提供内置工作台。
- 支持连接配置导入、导出，以及从 JetBrains 的 `.idea/dataSources.xml` 迁移。数据库密码和 API Key 在各设备分别绑定。

最低平台构建为 262。内置工作台已在 IntelliJ IDEA 免费模式和 Android Studio 中实测 H2 文件库。在 WebStorm 中已验证原生数据库模块启用时的窗口分流。安装、升级及实测范围见 [0.1.1 升级指南](<0.1.1 升级指南.md>)。

## Marketplace 英文文案

**MyBatis Workbench 0.1.1 adds a database workspace**

Free Enhanced MyBatis2 is now MyBatis Workbench. Browse database objects and run queries in the built-in workspace. With the Java plugin enabled, generate MyBatis entities, mapper interfaces, and XML from relational tables. Generated Mapper SQL quotes database, schema, and table names containing spaces according to the database dialect. INSERT statements retain all manually assigned composite key columns. Select multiple tables from the same data source and check for Java output name collisions before any files are written.

The workspace supports seven JDBC databases plus Redis, MongoDB, and Elasticsearch. JDBC drivers are resolved from Maven Central by default, with an option to use a custom repository. Existing SQLite and H2 files can be selected directly. Open table data and read-only DDL in separate editor tabs. Filter, sort, and edit table data. Double-click an editable cell or enter values column by column when adding a row. Import or export CSV. Preview or save SQL drafts generated by table structure comparison. Run the SQL statement at the caret or execute the current text selection. Estimated plans accept one statement. Open a SQL console from a MySQL or MariaDB database or a PostgreSQL or H2 schema to use that scope for queries, estimated plans, and completion. Filter Redis keys and browse results by cursor in standalone and cluster modes. Whole-key deletion checks the captured content and rejects oversized composite keys or streams with consumer groups. Add MongoDB documents field by field or with Extended JSON. Double-click a MongoDB field to edit its value, or an Elasticsearch result row to open its document editor. Refreshing the Redis, MongoDB, or Elasticsearch target list keeps the selected target when it is still available. The workspace is available when the host’s professional database tools are unavailable. Connection profiles can be imported, exported, or migrated from JetBrains data source files. Credentials are configured on each device.

Requires IntelliJ Platform build 262 or later. H2 file databases were smoke-tested with the built-in workspace on macOS in IntelliJ IDEA free mode and Android Studio. WebStorm was checked for native database window routing.
