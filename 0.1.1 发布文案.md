# MyBatis Workbench 0.1.1 发布文案

## 发布标题

MyBatis Workbench 0.1.1 带来内置数据库工作台

## 发布正文

Free Enhanced MyBatis2 更名为 **MyBatis Workbench**。这一版加入数据库工作台，可连接数据库、浏览对象和执行查询。在启用 Java 插件的宿主中，也可以从关系库表节点生成 MyBatis 实体、Mapper 接口和 XML。

- 支持 MySQL、PostgreSQL、MariaDB、SQLite、SQL Server、Oracle、H2，以及 Redis、MongoDB、Elasticsearch。
- JDBC 驱动默认从 Maven Central 下载，也可配置自定义仓库。SQLite 和 H2 可直接选择已有数据库文件。
- 支持连接配置导入、导出，以及从 JetBrains 的 `.idea/dataSources.xml` 迁移。数据库密码和 API Key 在各设备分别绑定。

最低平台构建为 262。数据库工作台已在 IntelliJ IDEA 免费模式、Android Studio、DataGrip 和 PyCharm 中抽测运行。安装、升级及实测范围见 [0.1.1 升级指南](<0.1.1 升级指南.md>)。

## Marketplace 英文文案

**MyBatis Workbench 0.1.1 adds a database workspace**

Free Enhanced MyBatis2 is now MyBatis Workbench. Browse database objects and run queries in the built-in workspace. With the Java plugin enabled, generate MyBatis entities, mapper interfaces, and XML from relational tables.

The workspace supports seven JDBC databases plus Redis, MongoDB, and Elasticsearch. JDBC drivers are resolved from Maven Central by default, with an option to use a custom repository. Existing SQLite and H2 files can be selected directly. Connection profiles can be imported, exported, or migrated from JetBrains data source files. Credentials are configured on each device.

Requires IntelliJ Platform build 262 or later. The database workspace was smoke-tested on macOS in IntelliJ IDEA free mode, Android Studio, DataGrip, and PyCharm.
